CORRECTED STARTUP BLOCKER
AddExternal searched an initially empty root list with FINDSTR. A normal no-match
sets ERRORLEVEL to 1; a successful ECHO does not clear that inherited status.
The old post-append IF ERRORLEVEL therefore treated a successful first insertion
as failure. AddExternal now calls ClearError (EXIT /B 0) before the append and
retains the write-failure check. This also fixes each later new-root insertion.

AXIOM AUDIT FOLLOW-UP
Lean issue 15226 documents an under-reporting risk in exported collectAxioms
results. The pinned Lean 4.33.0 CollectAxioms source includes that mechanism.
LeanPaper.AxiomWalk implements a visited-only graph union over a private
constant environment, without exported per-declaration axiom-cache results.
It records missing constants and rejects them rather than silently accepting
an incomplete graph. KernelAudit must use this graph's allowlist check as its
authoritative gate. Imported declarations, constructor types, mutual inductives,
recursor rules, theorem bodies and opaque bodies are traversed.

LIMITATIONS
External caches, runtime binaries and package sources must remain immutable
during a run; full external-tree hashing occurs once. Hash verification can be
costly. Static parser/control-flow checks are not a native Windows PASS receipt.
The graph walker is executable audit machinery, not a formally verified auditor.
Release packaging must refresh source hashes, dependency graph, audit ownership
list, exact targets, ledger, runner hash and archive manifest together.
